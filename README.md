# StoryLens

StoryLens is the master knowledge base and production framework for creating researched, illustrated YouTube stories.

This repository does not contain individual video productions. Each video is a separate project stored outside this repository.

Start with the [StoryLens Wiki](wiki/index.md).

## Repository contents

```text
wiki/
  index.md          canonical navigation
  project/          vision and current status
  framework/        repeatable video-project workflow
  standards/        research, script, visual, voice, audio, and editing rules
  experiments/      reusable learning from tests
  decisions/        channel-level decisions
  templates/        checklists copied into new video projects
```
