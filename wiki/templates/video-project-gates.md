# Video-Project Gates Checklist

Copy this checklist into a new video project's working notes and record the decision, date, reviewer, and required corrections for each gate.

## 1. Topic gate

- [ ] One-sentence premise
- [ ] Defined audience promise
- [ ] Strong title/thumbnail territory
- [ ] Reliable evidence available
- [ ] Adequate visual variety
- [ ] Risks identified

## 2. Research lock

- [ ] Claim ledger complete
- [ ] Primary or authoritative sources prioritized
- [ ] Confirmed, interpreted, reconstructed, and avoid categories visible
- [ ] Central narrative does not rely on an unsupported claim
- [ ] Creator approved factual treatment

## 3. Story gate

- [ ] Main question defined
- [ ] Hook confirms packaging promise
- [ ] Complications and payoffs mapped
- [ ] Ending answers or meaningfully reframes the main question
- [ ] Creator approved story shape

## 4. Script gate

- [ ] Every line has a useful function
- [ ] Script sounds natural when read aloud
- [ ] Every important line is visualizable
- [ ] Attention-drift passage rewritten
- [ ] Facts checked against claim ledger
- [ ] Narration evaluator passed

## 5. Prototype gate

- [ ] Finished 45–60 second section
- [ ] Final-quality voice
- [ ] Target visual cadence
- [ ] Representative animation
- [ ] Music, ambience, effects, and captions
- [ ] Tested without explanatory context
- [ ] Creator approved

## 6. Narration lock

- [ ] Performance sections directed
- [ ] Pronunciation and emphasis checked
- [ ] Pace and pitch vary naturally
- [ ] Timestamped transcript created
- [ ] Creator approved final performance

## 7. Visual gate

- [ ] Visual bible and reference sheets complete
- [ ] Every narration clause mapped
- [ ] Every selected asset individually passed
- [ ] Contact-sheet continuity passed
- [ ] Visual cadence target met
- [ ] No anachronisms, artifacts, or dignity failures

## 8. Picture lock

- [ ] Edit maintains attention and comprehension
- [ ] Sound hierarchy works on phone and headphones
- [ ] Captions are accurate and readable
- [ ] Reconstruction labels and citations are correct
- [ ] Technical master passed
- [ ] Creator approved

## 9. Release and learning

- [ ] Title and thumbnail match the opening
- [ ] Up to three thumbnails prepared for testing
- [ ] Processed YouTube upload checked before publication
- [ ] Retention, dips, spikes, top moments, and comments reviewed
- [ ] Video-project postmortem written
- [ ] No more than three reusable lessons added to the wiki
