# Short Video Gates

Copy this checklist into every Short project.

## Concept gate

- [ ] One complete idea
- [ ] One-sentence viewer promise
- [ ] Evidence available
- [ ] Strong first-frame concept
- [ ] Clear payoff
- [ ] Visually feasible in 15–25 beats

## Script gate

- [ ] Opening works in the first two seconds
- [ ] Approximately 90–150 words
- [ ] Every line performs a useful job
- [ ] One question and one payoff
- [ ] Sounds natural when read aloud
- [ ] Facts checked
- [ ] No generic CTA after the payoff

## Voice gate

- [ ] Final-quality performance generated or recorded
- [ ] Pace, pitch, pauses, and emphasis vary naturally
- [ ] Important lines auditioned in alternatives
- [ ] Listening test passed without reading the script
- [ ] Intelligible on a phone speaker

## Animatic gate

- [ ] Native 9:16 composition
- [ ] Approximately 15–25 meaningful visual beats
- [ ] New visual idea approximately every 1.5–3 seconds
- [ ] One focal point per beat
- [ ] Representative limited animation included
- [ ] No long static-image holds disguised by zooming

## Final gate

- [ ] Visual artifacts and historical errors cleared
- [ ] Music and effects support the narrative arc
- [ ] Captions readable within mobile safe areas
- [ ] Audio mix tested on phone and headphones
- [ ] Ending lands without unnecessary filler
- [ ] Creator approved the complete viewing experience

## Post-release review

- [ ] Shown in feed recorded
- [ ] Chose to view versus swiped away recorded
- [ ] Engaged views recorded
- [ ] Retention, completion, and rewatches reviewed
- [ ] Comments, shares, subscribers, and confusion noted
- [ ] Production time recorded
- [ ] One reusable lesson identified
